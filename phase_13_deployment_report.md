## 2. INSTRUCTIONS EXPLICITES D'IMPORTATION SUR SHOPIFY ADMIN

### Étape 1 : Téléchargement du Thème
Récupérez l'archive officielle du thème : [`tornado-shopify-theme-v1.0.0.zip`](file:///home/hahi17/Bureau/TORNADO/tornado-shopify-theme-v1.0.0.zip).

### Étape 2 : Importation dans Shopify
1. Connectez-vous à votre interface **Shopify Admin**.
2. Naviguez vers **Vente en ligne (Online Store) > Thèmes**.
3. Dans la section *Bibliothèque de thèmes*, cliquez sur **Ajouter un thème > Importer le fichier zip**.
4. Sélectionnez `tornado-shopify-theme-v1.0.0.zip` et validez l'importation.

### Étape 3 : Personnalisation via Theme Editor
1. Cliquez sur **Personnaliser** sur le thème TORNADO importé.
2. Modifiez le logo, les bannières Hero, les collections mises en avant et la barre d'annonce.
3. Testez l'affichage mobile et desktop dans l'aperçu.

### Étape 4 : Publication
1. Lorsque la configuration vous convient, cliquez sur **Actions > Publier**.
2. Votre boutique TORNADO est immédiatement en ligne et opérationnelle.
